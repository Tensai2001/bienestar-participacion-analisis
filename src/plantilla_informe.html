Cómo se construyó

El informe se genera automáticamente desde la base: al cambiar los datos, se vuelve a ejecutar un solo script.

  1. Validación de la baseSe verifica que existan todas las columnas esperadas antes de calcular.
  2. Depuración de repetidosRegistros con el mismo estudiante, fecha, área y actividad se cuentan una sola vez.
  3. Detección de cargues masivos
  4. Indicadores y alertasSe calculan con Python (pandas) y se guardan en indicadores.json para trazabilidad.
  5. InformeLos indicadores se insertan en una plantilla HTML con Chart.js, publicada con GitHub Pages.
